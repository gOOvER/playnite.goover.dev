How to Install in Playnite

Choose the method that works best for you — from instant 1-click browser integration to manual package drops.

01

1-Click Browser Install

Recommended • Instant

Click the orange "Install in Playnite" button on any item card. Your browser will prompt to open Playnite via its native playnite:// protocol.

  • Click "Install in Playnite"
  • Allow browser to open Playnite
  • Confirm installation dialog inside Playnite
02

Direct Package Download

Offline • Self-Hosted

Every add-on is hosted directly on this domain. Download the .pext (plugin) or .pthm (theme) file directly from our server.

  • Click "Download .pext / .pthm"
  • Double-click the downloaded file
  • Or drag & drop directly into the Playnite window
03

Playnite Addon Browser

Built-in • Auto-Updates

Find our verified extensions directly inside Playnite's native add-on manager with automated update notifications.

  • Press F9 in Playnite to open Settings
  • Go to Add-ons → Browse
  • Search for the add-on name and click Install

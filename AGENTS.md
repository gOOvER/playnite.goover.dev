# AGENTS.md — Standing Rules for playnite.goover.dev

This file defines the standing agreements and automated workflow rules for this repository.

---

## 🚀 Automated Deployment & Git Workflow

- **Always Push Immediately**: Whenever changes are made to `playnite.goover.dev` (HTML, CSS, JS, assets, downloads, docs), stage, commit, and **push them immediately to `origin/main`**. Do not wait for manual user requests to push.

---

## 🎨 Design System & Aesthetics

- **Strict 8px Rounded Corners**: All interactive elements, cards, modal dialogs, buttons, tab pills, and code containers must follow the 8px corner radius rule (`border-radius: 8px`).
- **Language Policy**: All content, documentation, guides, and commit messages must be written in **English**.
